# ArchMuse -- dependencias directas, con version exacta.
#
# Por que `==` y no `>=` (REFACTOR_MASTERPLAN tarea 12, 2026-08-18): hasta hoy
# las 13 dependencias de este archivo eran `>=` sin techo, asi que
# `pip install -r`
# instalaba lo ultimo que hubiera ese dia. Un `pip install` dentro de seis
# meses no reproducia el entorno de hoy, y el candidato mas probable a
# romperlo es el SDK de Anthropic, que publica versiones cada pocas semanas.
# Estas son las versiones con las que la suite pasa en verde HOY: es congelar
# lo que ya funciona, no elegir versiones nuevas.
#
# Los tres archivos y para que sirve cada uno:
#   requirements.txt       de que depende el PRODUCTO, y por que (esto).
#   requirements-dev.txt   lo anterior + pytest. Es lo que instala el README.
#   requirements.lock.txt  las 58 distribuciones exactas, transitivas
#                          incluidas. Lo que hay que usar en un despliegue.
#
# Como subir una version: cambiar el numero aqui, `pip install -r
# requirements.txt`, ejecutar `pytest` entero, y si queda en verde regenerar el
# lock con `pip freeze > requirements.lock.txt`. Nunca al reves.
